# First Instar *Drosophila* Larval Connectome
Pancrustacean nervous systems exhibit remarkable stereotypy, with conserved neuronal morphologies and projection patterns that persist across metamorphosis and species boundaries. We used these developmental “anchor points” to establish a unifying framework for comparative connectomics using the *Drosophila* first-instar larval central brain connectome (~4,000 neurons, ~550,000 synapses). We assigned every neuron to its developmental lineage, distinguishing differentiated and undifferentiated categories, and morphologically clustered them to define neuron types. Differential projection and innervation patterns of these neuron types delineated neuropil compartments, yielding a systematic, hierarchical nomenclature grounded in lineage origin, morphology, and connectivity — directly alignable to adult *Drosophila* connectomes and emerging cross-species datasets. Embedding these anatomically defined classes into a low-dimensional latent space uncovered connectivity modules. This enabled functional inferences of previously undescribed neurons based on their developmental origins and network contexts. Finally, comparative analysis of lineage organization between larval and adult connectomes identified conserved axonal tract scaffolds that endure pupal remodeling, demonstrating that early-established lineage-based layouts provide a stable reference frame for adult brain assembly. Thus, we assemble a comprehensive atlas documenting every developmental lineage, sensory afferent population, and neuropil compartment in the larval brain. By integrating high-resolution connectomics and developmental analysis, this resource provides a scaffold for dissecting conserved principles of circuit architecture and modifications underlying functional diversity across developmental stages and evolutionary divergence.
